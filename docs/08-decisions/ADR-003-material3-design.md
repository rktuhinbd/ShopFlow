# ADR-003 — Material 3 Design Language

**Status**: ACCEPTED  
**Date**: 2026-08-27  
**Deciders**: Principal Android Architect (Agentic)

## Context

The app needs a visual design system. Options include Material 2, Material 3, or a custom design system.

## Decision

Use Material 3 (Material You) as the primary design system, with dynamic color support on Android 12+.

## Consequences

**Positive**: Modern Android-native appearance; dynamic color; built-in dark mode; consistent component library; accessibility built-in.

**Negative**: Some Material 3 components are still evolving; may need custom theming for brand identity.

## Alternatives Considered

1. **Material 2**: Stable but outdated appearance
2. **Custom design system**: Maximum control but enormous effort for a catalog app
