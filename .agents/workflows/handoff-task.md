# Workflow: Handoff Task

## Trigger
Before ending a work session or switching tasks/agents.

## Required Updates
1. Update the task file with current status and progress
2. Update `docs/07-status/CURRENT_WORK.md`:
   - Current task and purpose
   - Files modified
   - Completed substeps
   - Remaining substeps
   - Known issues
   - Next action
   - Verification command
3. Update `docs/07-status/PROJECT_STATUS.md`
4. Update `docs/07-status/NEXT_ACTIONS.md`
5. Update `docs/07-status/COMPLETED_WORK.md` (if task completed)
6. Update ADRs if decisions were made
7. Commit all changes

## Handoff Must Include
- What changed
- What is verified
- What is unverified
- What failed
- Remaining work
- Exact next step
- Verification command
- Known risks
