# Workflow: Start Task

## Trigger
Beginning work on any task.

## Steps
1. Read `AGENTS.md`
2. Read `docs/07-status/PROJECT_STATUS.md`
3. Read `docs/07-status/CURRENT_WORK.md`
4. Read `docs/07-status/NEXT_ACTIONS.md`
5. Run `git status` and `git log --oneline -5`
6. Identify the current task from `docs/06-planning/TASK_BACKLOG.md`
7. Read the task file from `tasks/`
8. Read relevant ADRs from `docs/08-decisions/`
9. Read relevant architecture/requirement docs
10. Update task status to `IN_PROGRESS`
11. Update `CURRENT_WORK.md` with what you are about to do
